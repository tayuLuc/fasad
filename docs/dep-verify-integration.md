## Синтез
1. Универсальная поверхность = OpenAI-совместимый `base_url` fasad (факт 3): интеграция = один конфиг-ключ, правок SDK не требует ни один клиент — контракт «мы = то, что делает любой OpenAI-клиент» подтверждён первичкой.
2. Нативные хуки под внешний текст-трансформ: LiteLLM generic_guardrail_api (факт 1, fail-closed дефолтно) и CustomGuardrail (факт 2), Hermes `llm_request` (факт 5); LangChain PIIMiddleware — только код клиента.
3. Кандидат следующего шага: адаптер fasad под контракт generic_guardrail_api (`BLOCKED`/`GUARDRAIL_INTERVENED`) поверх нашей маскировки — десятки строк.
4. Только policy-блокировка без трансформации текста — CrewAI, n8n (факты 3,4): для них путь один, base_url.
5. Sidecar-модель — отраслевая норма (Presidio, LLM Guard — факты 6,7): платят torch-рантаймом и стейтом; наше отличие — Rust, <2 ГБ, RU-форматы.
6. Возвратной деанонимизации ответа нет ни у managed-игроков (факт 8), ни у промеренных конкурентов — ниша fasad подтверждена отсутствием аналога в первичках.
